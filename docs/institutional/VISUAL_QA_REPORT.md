# Visual QA scope and evidence

The dedicated acceptance gallery requires actual running views: command center, glass component library, semantic icons, circular/semicircular/segmented/radar gauges, debate theater and objection tree, Authority Explorer, Responsibility Map, MAT calibration, iPhone RTL, and independently rendered Word/Excel previews. Synthetic fixture values are explicitly labelled; no mockup substitutes for a running application screenshot.

Engineering review assesses hierarchy, legibility, Arabic/RTL layout, original logo geometry, glass treatment, chart definitions, unknown states, mobile overflow and cross-format readability. Automated axe scans cover overview and component library; keyboard tests exercise Tab/Enter skip navigation and graph alternatives. Historical timeline inspection is labelled recorded and does not animate it as current provider inference.

Known limits remain visible: creative branding approval and official typography/safe-area guidance pending; Microsoft Excel desktop fidelity, manual screen-reader/UAT and production-scale performance not verified. The radar has independent denominators and is not an overall governance rating. Dense source graphs are bounded/filterable. Native Excel sparkline extension fidelity differs by editor. Transient React Flow sizing warnings on lazy mounting are not hidden; rendered node counts/drill-downs are verified.

Execution results and exact final SHA/CI links belong in docs/codex/TEST_EVIDENCE_REGISTER.md and the final PR handoff. Institutional design/security acceptance remains PENDING_AUTHORIZATION even when the automated visual gallery gate passes.
