# Cross-format visual acceptance

One read model and shared rendering specification feed Arabic web instruments, Word tables/comments/artwork, native Excel charts/formulas/tables and PDF. Each metric carries definition, numerator/denominator, source-record IDs, calculation date, threshold basis, evidence status, synthetic flag and unknown handling. A hard gate cannot be offset by aggregate scores.

Word/PDF include original authorized branding, an executive cover, explicitly static gauges, editable metrics/debate/source tables, native automated provenance comments, source-linked authority/responsibility summaries and permanent internal-draft labels. They do not fabricate tracked changes or human comments/signatures. The existing original-document native-comment/revision engine remains separate and unchanged.

Excel includes native editable doughnut charts, formulas, structured tables, category conditional formatting, event/observation/source/version/authority/responsibility registers, KPI counts and an x14 event-count sparkline. Text cells cannot become injected formulas. The sparkline uses actual event sequence counts, never invented time-series values. Excel supports this native extension; openpyxl and some other editors may remove it on resave. The original delivered file is retained and tested separately from recalculation copies. Microsoft Excel desktop rendering is NOT_RUN here.

`tools/generate_visual_exports.py` produces only fictional samples, renders Word and Calc to PDF using stable LibreOffice, rasterizes the actual pages and independently reconciles every metric fraction in a separate workbook copy. Source files remain unchanged; unknown measures stay blank/unknown. `tools/build_visual_gallery.py` requires actual browser/application and document captures, checks hashes/dimensions and creates a standalone gallery/manifest. Missing required captures fail the visual gate.

Private exports use identical semantic rendering after the same case/reference/brand permissions as private reads. They remain INTERNAL_DRAFT / NOT_AUTHORIZED. Source catalog membership is never presented as case evidence unless explicitly attached through the evidence registry.
