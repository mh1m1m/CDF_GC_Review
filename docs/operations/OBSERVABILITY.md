# Privacy-preserving operational evidence

Admin health reports actual database/audit integrity, job-state counts, queue/execution means, human backlog, source-based verified API completions and measured copilot operation durations/errors. Executor readiness distinguishes installed/configured/permitted from authenticated/tested; missing completion receipts remain NOT_VERIFIED. Costs stay NULL without legitimate provider accounting.

Metrics store bounded server operation names, outcome class, elapsed milliseconds and timestamps. They do not store raw conversations, source paragraphs, provider keys or session credentials. Existing traces retain role-specific execution IDs and source classification. Operational health is role-protected; aggregate counts do not expose foreign case bodies. Provider exceptions are sanitized by existing adapters.

Acceptance artifacts capture observed tool/CLI/browser/export timings and hardware/runtime inventory where available. These are baseline measurements on a given environment, not performance achievements or production targets. Dashboard values retain numerator/denominator/lineage and unknown statuses. More detailed production tracing/alerting and organizational retention ownership require separate setup.
