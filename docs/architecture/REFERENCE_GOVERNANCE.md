# Reference governance

The current architecture separates PUBLIC_SYNTHETIC_DEMO from PRIVATE_INSTITUTIONAL. See [institutional integration](../institutional/INSTITUTIONAL_REFERENCE_INTEGRATION.md), [DoA validation](../institutional/DOA_EXTRACTION_VALIDATION.md) and [organizational mapping](../institutional/ORGANIZATION_RESPONSIBILITY_MAPPING.md).

The public provider uses shared/demo-reference-fixtures.json. Real originals, extraction candidates and source hashes belong to the ignored private registry, with default-deny runtime access. The earlier user-authorized public dataset is removed from the current shared distribution without rewriting PR #8 history. Access, publication permission, source identity, approval, effective date and supersession remain distinct.
